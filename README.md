# Research: Cross-Chain DEX

Obsidian vault containing comparative research on cross-chain DEX
architectures, with a focus on middle-chain swap settlement (Serai,
Thorchain) versus attestation bridges (Wormhole), and how the Logos
Execution Zone (LEZ) could position itself as a privacy-preserving
middle layer.

## Structure

- `projects/` — one atomic note per project (Serai, Thorchain, Wormhole, LEZ-positioning)
- `patterns/` — recurring design patterns (TSS vaults, slip-based fees, lock-mint, etc.)
- `metrics/` — cross-project quantitative comparisons
- `sources/` — archived source material for offline fact-checking
- `summary.md` — synthesis and LEZ positioning analysis
