UnstoppableSwap completes 'eigenwallet' rebrand with GUI 3.0.0-beta release

The UnstoppableSwap1 project has completed its rebrand to eigenwallet2 with the 3.0.0-beta3 release of its GUI, in an effort to build the best non-custodial cross-platform Monero wallet4:

The project formerly known as UnstoppableSwap is now called eigenwallet and lives under a new GitHub organisation. [..] eigenwallet is an ambitious community effort to build the Monero wallet for the future.

Changes overview

* GUI: The GUI can now be used as a Monero wallet
* GUI: The internal Bitcoin wallet and the p2p identity is now tied directly to the Monero wallet
* GUI: The data directory has been split into multiple subdirectories

The complete changelog and binarybaron’s GPG signing key are available on Github5.

To verify the signatures and learn more about the BTC-XMR cross-chain atomic swaps project, consult the docs6 and the previous Monero Observer reports7.

Note: it is recommended to complete all pending swaps before upgrading. Join #unstoppableswap-core8 on Matrix to follow project development.

This is an ongoing story and the report will be updated when new information is available.
